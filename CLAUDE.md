# Frametanium: notes for Claude sessions

See README.md for what it does. Service: `manager.py` (stdlib Python, runs on the Frame). Headset app: `app/app.c`.

## Rules (from the 2026-10-20 review)
- **Auth:** every `/api/*` request needs a secret, loopback included. Headset app sends `X-Frametanium-Key` (`app_key`
  from `~/.config/frametanium/config.json`), the page sends `X-Key` (the `password`). Both are generated by
  `ensure_secrets()`. Never add a loopback/no-password bypass, never accept secrets in the query string, and keep
  `host_ok()` (Host allow-list + Origin check). Any auth change must change app.c and page.html together, and old
  headset apps must still get a readable "#" notice in TSV replies.
- Write settings files only with `save_json` (unique temp + fsync; `private=True` for config.json) and do
  read-modify-writes under `files_lock`.
- Test locally: run manager.py with `HOME=<scratch>` and a config.json with another port; build app.c natively
  (`gcc $(sdl2-config --cflags) app/app.c $(sdl2-config --libs)`) and screenshot with
  `SDL_VIDEODRIVER=dummy PM_SCREENSHOT=out.bmp PM_SCREEN=list`.
- Don't push, tag, release or deploy without the user's OK.
